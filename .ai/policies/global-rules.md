# Global Rules

## Hard Rules

1. Never say work is complete before verification evidence exists.
2. Only one feature may be `in_progress` at a time.

## Delivery Rules

- Read the active task and feature list before changing code.
- Stay inside the current feature scope.
- Preserve the `nanovllm` import API unless the active feature says otherwise.
- Record GPU limitations explicitly; never convert an unavailable runtime into a silent pass.
- Keep the root and `.ai` feature-list copies identical.
- Escalate blockers instead of silently broadening scope.
