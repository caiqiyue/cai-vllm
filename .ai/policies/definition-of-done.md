# Definition Of Done

A feature is done only when all are true:

1. The active feature was implemented within its recorded scope.
2. Review accepted the change for verification.
3. Relevant lightweight and runtime checks were executed.
4. Evidence was written under `evidence/` and linked from the feature record.
5. Both feature-list copies were updated identically.
6. The repository remains restartable through `init.sh` or `init.ps1`.

Compilation alone, unexecuted tests, manual reasoning, or an implementer's assertion are not sufficient.
